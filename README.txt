هوشی — نسخه وب قابل نصب (PWA)

این بسته APK نیست. فایل‌ها را در ریشه مخزن GitHub قرار دهید و GitHub Pages را فعال کنید. سپس سایت HTTPS را در Chrome اندروید باز کنید و از منوی سه‌نقطه گزینه Install app یا Add to Home screen را بزنید.

این نسخه به تبدیل متصل نیست، قیمت زنده نمی‌گیرد و سفارش ثبت نمی‌کند. کلید API، رمز عبور یا عبارت بازیابی کیف پول را وارد نکنید.
